# bf - обзор продукта

> Единственный документ «что это и куда движется». Простым языком, актуальный; новый разработчик, владелец или агент должен получить картину за 5 минут.

## What it is

Платформа для одного человека - владельца (домен malinina.ca). По его словам, она должна обслуживать все его потребности: помогать понимать процесс готовки; вести бизнес - продажи, планирование, приём платежей, аналитика; и давать ChatGPT доступ через MCP, которым владелец пользуется для продвижения и построения автоматизированного решения для продаж и производства.

## What people do today instead

Заказы принимаются в мессенджерах, учёт и планирование ведутся в таблицах или заметках, платежи - наличными или e-transfer, никакой платёжный сервис пока не подключён. ChatGPT используется отдельно, без связи с данными бизнеса (подтверждено владельцем, 2026-11-05).

## Vision

Одна платформа, в которой знания о готовке, заказы, платежи и аналитика связаны, а автоматизацию продаж и производства ведёт ChatGPT через MCP по поручению владельца. Горизонт 6-18 месяцев и ставка - не определены (backlog PRODUCT-1).

## Current state (as of 2026-11)

Чистый лист: кода, инфраструктуры и стека нет; прототип удалён (ADR-006). Есть только основа - правила, стандарт, база знаний.

- **Live:** ничего.
- **In progress:** выбор стека и первая спека (backlog STACK-1, SPEC-1).
- **Not started / planned:** курсы, заказы, платежи, аналитика, MCP-сервер для ChatGPT, часть о готовке.

Владелец-оператор (основная), клиент, ChatGPT через MCP - [`personas.md`](personas.md), черновик ждёт подтверждения (PERSONAS-1).

## Non-goals

Платформа не маркетплейс и не многопользовательский магазин; в её рамках не принимаются решения за владельца, касающиеся денег, права и безопасности (BDR-001). Также сознательно не делает (подтверждено владельцем, 2026-11-05):
- не вводит роли и доступ для команды, пока работает один человек;
- не строит собственную платёжную систему (сейчас наличные и e-transfer; будет ли внешний провайдер - не решено);
- ChatGPT через MCP не публикует, не платит и не удаляет без подтверждения владельца.
