# bf - обзор продукта

> Единственный документ «что это и куда движется». Простым языком, актуальный; новый разработчик, владелец или агент должен получить картину за 5 минут.

## What it is

Платформа malinina.ca для одного человека - владельца. По его словам, она должна обслуживать все его потребности: помогать понимать процесс готовки; вести бизнес - продажи, планирование, приём платежей, аналитика; и давать ChatGPT доступ через MCP, которым владелец пользуется для продвижения и построения автоматизированного решения для продаж и производства.

## Vision

Одна платформа, в которой знания о готовке, заказы, платежи и аналитика связаны, а автоматизацию продаж и производства ведёт ChatGPT через MCP по поручению владельца. Горизонт 6-18 месяцев и ставка - не определены (backlog PRODUCT-1).

## Current state (as of 2026-11)

- **Live:** на malinina.ca открыта страница «скоро открытие» для Валерии (фото торта); работают edge-шлюз `api` (проверка JWT, роли, ограничение частоты, прокси), сервис `auth` (токены RS256, refresh, logout, JWKS, dev-token), оркестратор сна и пробуждения сервисов на ECS Fargate; конвейер от PR до продакшена.
- **In progress:** сервисы-скелеты `order`, `course`, `billing`, `admin`, `ai` без бизнес-логики; ветка с панелью инфраструктуры в `admin` не слита.
- **Not started / planned:** курсы, заказы, платежи, аналитика, MCP-сервер для ChatGPT, обучающая часть о готовке.
