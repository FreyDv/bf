# bf - обзор продукта

> Единственный документ «что это и куда движется». Простым языком, актуальный; новый разработчик, владелец или агент должен получить картину за 5 минут.

## What it is

Платформа для владельца (Даня) и его жены Валерии, кондитера (домен malinina.ca), и витрина для их покупателей в Ниагарском регионе. По словам владельца, она должна обслуживать все его потребности: помогать понимать процесс готовки; вести бизнес - продажи, планирование, приём платежей, аналитика; и давать ChatGPT доступ через MCP, которым владелец пользуется для продвижения и построения автоматизированного решения для продаж и производства.

## What people do today instead

Заказы принимаются в мессенджерах, учёт и планирование ведутся в таблицах или заметках, платежи - наличными или e-transfer, никакой платёжный сервис пока не подключён. ChatGPT используется отдельно, без связи с данными бизнеса (подтверждено владельцем, 2026-11-05).

## Vision

Одна платформа, в которой знания о готовке, заказы, платежи и аналитика связаны, а автоматизацию продаж и производства ведёт ChatGPT через MCP по поручению владельца. Горизонт 6-18 месяцев и ставка - не определены (backlog PRODUCT-1).

## Current state (as of 2026-11)

Продуктового кода нет. Прототип удалён (ADR-006); с чистого листа выбран технологический стек ([ADR](decision-records/adr/README.md)), собран каркас монорепо с пустыми приложениями backend и frontend и проверкой границ архитектуры (ADR-014).

- **Live:** ничего; ни одна возможность не работает для владельца.
- **In progress:** первая спека возможности (backlog SPEC-1); открытые решения по доступу и безопасности (AUTH-1, SEC-1).
- **Not started / planned:** курсы, заказы, платежи, аналитика, MCP-сервер для ChatGPT, часть о готовке.

## Users / personas

Владелец-оператор (Даня, основная), кондитер (Валерия), покупатель, ChatGPT через MCP - [`personas.md`](personas.md), подтверждено владельцем 2026-11-11 (BDR-001).

## Key capabilities

Пока нет: спеки пишутся командой `/spec-specify` из слов владельца (backlog SPEC-1).

## Non-goals

Платформа не маркетплейс и не многопользовательский магазин; в её рамках не принимаются решения за владельца, касающиеся денег, права и безопасности (BDR-001). Также сознательно не делает (подтверждено владельцем, 2026-11-05):
- не вводит роли для команды сверх двух аккаунтов: у Дани и Валерии раздельная авторизация, права раздаёт Даня (подтверждено владельцем 2026-11-11, AUTH-1);
- не строит собственную платёжную систему (сейчас наличные и e-transfer; будет ли внешний провайдер - не решено);
- ChatGPT через MCP не публикует, не платит и не удаляет без подтверждения владельца.
