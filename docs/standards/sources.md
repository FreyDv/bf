## External sources the two references cite

The Domain-Driven Hexagon README cites 202 external pages (articles, papers, books, talks,
package pages); the standard conforms to or borrows from 13 formats and practices and cites 20
sources in its working-with-AI notes. Each is digested under `digests/` (see the index in
[`README.md`](README.md)); the digests record which pages could not be fetched and what was
taken from model knowledge instead, labelled as such.
