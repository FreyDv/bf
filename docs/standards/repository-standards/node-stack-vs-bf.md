# Node stack (Layer 2) compared with this repository

The picks of `repository-standards/node` 0.3.1 ([DECISIONS](../vendor/repository-standards-node/DECISIONS.md), digest in [`digests/D4-node-stack.md`](../digests/D4-node-stack.md)) set against what bf does today. The stack targets one application; bf is a multi-service monorepo with its own tooling, so the standard's own rule applies: take the portable parts, record the rest as exceptions (`stack.manifest.json`). Wave order follows the standard: what protects, then what shapes code, then what proves, then what automates (backlog STACK-1).

| Area                    | Stack pick                                                                           | bf today                                                                                              | Status                                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Package manager         | pnpm, pinned via `packageManager` + `engines`                                        | pnpm 10.15.0, pinned                                                                                  | aligned                                                                                                         |
| Node                    | 24.18.0 in `.nvmrc`                                                                  | Node 26 (`.nvmrc` 26, `engines >=26`)                                                                 | **deviation**, ADR-031, exception on `.nvmrc`                                                                   |
| Task runner             | Turborepo                                                                            | Turborepo                                                                                             | aligned                                                                                                         |
| Lint + format           | Biome (+ Prettier for SCSS)                                                          | ESLint 10 flat + Prettier                                                                             | **deviation**, ADR-002, file exception on `biome.json`                                                          |
| TypeScript              | strict + `noUncheckedIndexedAccess`, `noImplicitOverride`, ...                       | strict base in `packages/config/tsconfig/base.json`, TypeScript 6                                     | partly aligned; extra flags to verify (STACK-1); exception on `tsconfig.base.json` (base lives in `@bf/config`) |
| Supply chain            | 7-day `minimumReleaseAge`, `allowBuilds`, `enablePrePostScripts: false`, `saveExact` | policy keys added to `pnpm-workspace.yaml`; catalog still `^` ranges; pnpm 10.15 predates the setting | **in progress**, ADR-030, PINS-1                                                                                |
| Env config              | zod schema validated at boot                                                         | zod schema per service (`createEnvValidator`, `env:check`)                                            | aligned                                                                                                         |
| Request validation      | zod at the boundary                                                                  | zod contracts in `@bf/contracts`                                                                      | aligned                                                                                                         |
| Logging                 | pino, JSON to stdout, redacted                                                       | pino with redaction (`@bf/shared/logger`)                                                             | aligned                                                                                                         |
| Server framework        | Fastify, native plugin DI                                                            | NestJS 12 with DI                                                                                     | different archetype, not adopted (ADR-016, ADR-025)                                                             |
| Front end               | Next.js App Router, standalone, typed config, report-only CSP                        | Next.js 15 static export behind CloudFront                                                            | different deploy shape; security headers via CloudFront policy; CSP baseline not evaluated (backlog via REC-2)  |
| Auth                    | Better Auth / `openid-client`                                                        | own RS256 JWT issued by `auth`, verified at the edge                                                  | different, ADR-019                                                                                              |
| Styling                 | CSS Modules + SCSS + DTCG tokens                                                     | Tailwind 4 + shadcn-style `@bf/ui`                                                                    | the stack names Tailwind as a local escape hatch                                                                |
| Testing                 | Vitest + Playwright, tiered, Lighthouse perf budgets                                 | Jest (SWC) unit + e2e on Postgres, drift checks                                                       | **deviation**, ADR-029; no browser e2e or perf budget yet                                                       |
| CI                      | least-privilege permissions, pnpm cache, frozen lockfile                             | `pipeline.yml` with matrix per app, `ci ok`                                                           | aligned in shape; permissions and action pinning not audited line by line (CI-1)                                |
| Dependency updates      | Renovate, grouped minor/patch, same cooldown                                         | none                                                                                                  | open (STACK-1)                                                                                                  |
| Datastore + query layer | per-repo ADR (Postgres default)                                                      | Postgres + Drizzle, database per service                                                              | decided, ADR-003/018                                                                                            |
| Containers + deploy     | per-repo ADR                                                                         | Docker per app, ECS Fargate scale-to-zero                                                             | decided, ADR-023                                                                                                |

What the stack manifest requires and how it is met: `.nvmrc` (content exception), `biome.json` and `tsconfig.base.json` (file exceptions with reasons), `pnpm-workspace.yaml` keys `minimumReleaseAge`, `saveExact`, `enablePrePostScripts` (added), and the guard `pnpm check:all` (script added: format check, typecheck, lint). Optional entries (Vitest and Playwright configs, test docker compose, `perf/`, Renovate, CI templates) are not carried and are not drift.
