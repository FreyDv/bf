# BDR-002: Бюджет платформы: 100-150 USD в месяц, простой стоит ноль

|                |            |
| -------------- | ---------- |
| **Status**     | Accepted   |
| **Date**       | 2026-11-05 |
| **Author**     | владелец   |
| **Decided by** | владелец   |

## Context

Платформа - личный проект владельца без выручки на старте; архитектура AWS подчинена бюджету. Вариант Fargate + ALB + NAT + RDS стоил около 180 USD (ADR-022).

## Who it serves

Выигрывает владелец-оператор (счёт). Хуже живётся клиенту: первый запрос к спящему сервису занимает 30-60 с (503 с `Retry-After`).

## Options considered

- Всегда включённые сервисы - отклонено по цене.
- Сон до нуля задач с пробуждением по запросу (ADR-023) - выбрано.

## Decision

Месячный счёт платформы не выходит за 100-150 USD; сервисы без трафика стоят ноль (кроме постоянной части: ALB и всегда включённый `api`); каждая инфраструктурная правка называет свою месячную стоимость; никаких дополнительных хранилищ состояния (в том числе DynamoDB).

## Consequences

- Любой платный ресурс AWS требует ADR с ценой.
- Холодный старт - осознанная цена.

## Confirmation

Счёт AWS по месяцам; `cdk diff` в PR-комментарии показывает изменения инфраструктуры; бюджетные оповещения AWS Budgets - не проверено, backlog CI-1.

## What this rules out

Всегда включённые сервисы ради скорости первого запроса; DynamoDB и иные состояния ради оркестратора.

## How we would know we were wrong

Счёт стабильно превышает 150 USD или клиенты уходят из-за холодного старта.

## Revisit when

Появляется выручка, оправдывающая постоянные задачи, либо счёт выходит за границу бюджета.
