# ADR-063: Агент сам пушит, сливает PR на зелёном CI и решает технические развилки

| **Tags** | security, process, agent |

## Context

- `git push` и `gh pr merge` стоят в `ask` базовых настроек стандарта (`.claude/settings.json`), скилл `backlog-burndown` (шаг 9) ждёт слова владельца на каждое слияние, а шаги 3-4 - его ответа на каждую развилку.
- За 2026-11-15 владелец трижды писал «да, сливай» и около десяти раз «ок, жду»: работа стояла на паузах, решения по существу владелец не менял.
- AGENT-2 (остаточные пробелы ask-списка ADR-056 п. 6) теряет смысл в прежней форме: часть про `helm` снял ADR-059, а владелец решил расширить права агента, а не латать список.
- Кластер не продакшен (ADR-059): слияние в `main` выкатывает приложение на `malinina.ca`, пользователей и данных там нет; откат - `git revert`.

## Options considered

| Развилка | Выбрано | Отклонено |
|---|---|---|
| Слияние | агент сливает сам, squash, только при зелёных обязательных проверках | слово владельца на каждый PR: паузы без пользы |
| Развилки | технические - агент по своей рекомендации, с записью; деньги и продукт - владелец | всё через владельца (5-10 вопросов на пункт); всё агенту: деньги и продукт - не его |
| Запись в настройки GitHub | остаётся у владельца | открыть агенту: ошибка в ruleset снимает защиту `main`, нужна раз в месяц-два |
| Жёсткие запреты | без изменений | ослабить: для самостоятельной работы не нужно |

## Decision

1. **Push и слияние.** Агент сам делает `git push` в свою ветку и `gh pr merge <n> --squash`, когда все обязательные проверки PR зелёные. Без `--admin`, без `--delete-branch`, без слияния на красном или незаконченном CI.
2. **Технические развилки** агент решает сам по своей рекомендации и записывает решение там, где ему место (ADR - с «Decided by: агент по поручению владельца, ADR-063»). Владельцу - итог, а не вопрос.
3. **Владельцу остаётся:** новые платные ресурсы и расходы DO; продукт и пользователи (BDR, спеки, персоны); запись в настройки и секреты GitHub (`gh api` на запись, ADR-056 п. 3, 4); то, что владелец явно оставил за собой.
4. **Не меняется:** запись в удалённую БД, force-push, удаление веток, секреты и ключи в чате, argv, логах и файлах, правка хуков `.claude/hooks/**` - как было (AGENTS.md, ADR-056, ADR-059).
5. **`.claude/settings.json`:** из `permissions.ask` убраны `git push` (обе формы) и `gh pr merge *`; в `permissions.allow` добавлены `git push`, `gh pr create|view|checks|list|diff|merge` и `gh run view|list|watch`. `deny` (force-push, `--delete`, секреты, `gh api` DELETE) и хуки не тронуты.
6. **Заменяет** правило «слияние - по слову владельца» скилла `backlog-burndown` и п. 6 ADR-056 вместе со строкой AGENT-2: остаток шаблонов принят как есть, его закрытие - не цель. Скилл приведён к этой записи. Остальное в ADR-056 и ADR-059 в силе.

## Consequences

- Positive: пункт идёт от исследования до слияния без пауз; владелец видит результат и может откатить.
- Negative: ошибочное слияние сразу уходит на `malinina.ca`; цена низкая, пока там нет пользователей.
- Negative: технические решения принимаются без второго взгляда владельца; защита - записи ADR, ревью пяти линз в `backlog-execute` и CI.

## Confirmation

Review only; права - `.claude/settings.json` (`jq '.permissions'`), порядок работы - `.claude/skills/backlog-burndown/SKILL.md`.

## Revisit when

- На `malinina.ca` появятся реальные пользователи или их данные: вернуть слияние по слову владельца (тот же триггер, что у ADR-059).
- Слияние агента сломает `main` или выкат, и откат не поможет за один `git revert`.
