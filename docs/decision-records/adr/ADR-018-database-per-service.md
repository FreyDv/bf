## Context

Нужна жёсткая изоляция данных между сервисами при одном контейнере локально.

## Options considered

В исходной таблице альтернативы не записаны (заменяет pg-схемы из ADR-003).

## Decision

Один Postgres, по базе на сервис (`auth`, `order`, `course`, `billing`, `admin`; схема `public`), создаются `infra/postgres/postgres-init/01-init.sql` - ответ на развилку `datastore`. В проде - один кластер Aurora Serverless v2.

## Consequences

- Плюс: изоляция данных.
- Минус: нельзя делать join между сервисами.

## Confirmation

Каждый сервис ходит только в свою базу (проверка ревью); миграции per-service.

## Revisit when

Нужны транзакции между сервисами или аналитика поверх всех данных.
