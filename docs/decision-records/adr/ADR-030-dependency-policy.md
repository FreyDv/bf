## Context

Стандарт требует точных версий без диапазонов, lockfile и кулдауна релизов 7 дней (R21). Сейчас каталог pnpm содержит диапазоны `^`. Владелец выбрал вариант «дефолты стандарта».

## Options considered

- Оставить диапазоны - отклонено владельцем.
- Точные версии + кулдаун - выбрано.

## Decision

Цель: все зависимости (манифесты, overrides, образы, раннеры, actions) закреплены точно; lockfile в репозитории; новая версия проходит кулдаун 7 дней (`minimumReleaseAge: 10080` в `pnpm-workspace.yaml`); критичное исправление безопасности - временное исключение, не глобальное снижение; добавление зависимости требует ADR. Переход - PINS-1 (требует pnpm ≥ 10.16).

## Consequences

- Плюс: обновления только по проверенному диффу.
- Минус: ручной труд до автоматизации (Renovate - в стеке Layer 2, STACK-1).

## Confirmation

`node scripts/self-verify.mjs` (ключи `saveExact`, `minimumReleaseAge` в манифесте стека); ревью lockfile-диффа.

## Revisit when

Выходит pnpm, меняющий механику кулдауна, либо критичная уязвимость требует обхода кулдауна.
