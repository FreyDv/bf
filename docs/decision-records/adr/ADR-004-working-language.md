# ADR-004: Рабочий язык: код и коммиты - английский, документы и спеки - русский

## Context

- Язык в стандарте - настройка, не ограничение.
- Его нужно решить по типу артефакта и записать в `AGENTS.md`.

## Options considered

| Вариант | Итог |
|---|---|
| Всё по-английски | отклонён |
| Всё по-русски | отклонён |
| Разделение по типу артефакта | выбран |

## Decision

1. Английский: код, идентификаторы, имена файлов, коммиты, PR, вывод CI и гардов, инструкции агента (`AGENTS.md`, `CLAUDE.md`, `.claude/**`, `CONTRIBUTING.md`, `SECURITY.md`), `docs/standards/**`.
2. Русский: спеки, записи решений, `PRODUCT.md`, персоны, бэклог, discovery, идеи, runbooks, принципы, архитектура.
3. Синтаксис, который читают скрипты, не переводится.
4. Владелец и агент общаются по-русски.

## Consequences

- Плюс: одно правило на тип артефакта.
- Минус: часть справочных документов (`docs/standards/README.md` и др.) на английском.

## Confirmation

Ревью; гард `[NEEDS ...]` ловит переведённые маркеры.

## Revisit when

В команду приходит человек, не читающий по-русски.
