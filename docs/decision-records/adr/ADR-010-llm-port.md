## Context

Тесты не должны ходить в сеть; провайдер должен быть заменяем.

## Options considered

В исходной таблице альтернативы не записаны.

## Decision

`@bf/llm`: адаптер OpenAI за портом `LLM`, в тестах - `InMemoryLlm`.

## Consequences

- Плюс: тесты детерминированы, провайдер заменяем.

## Confirmation

`packages/llm`; сервис `ai` использует порт.

## Revisit when

Выбирается другой провайдер или модель с другой моделью вызова.
