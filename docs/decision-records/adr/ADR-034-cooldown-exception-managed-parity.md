# ADR-034: Исключение из кулдауна: версия, уже работающая в managed-сервисе

| | |
| --- | --- |
| **Status** | Accepted |
| **Date** | 2026-11-11 |
| **Author** | владелец |

| **Tags** | supply-chain, local, dependencies |

## Context

- ADR-005: всё закреплено точно, новая версия проходит кулдаун 7 дней (п. 3); исключение - только критичное исправление безопасности (п. 4).
- Postgres на DO (`bfdb`) уже работает на 18.6, которая вышла 2026-11-06; кулдаун по образу `postgres:18.6` кончается 2026-11-13.
- Локальная среда обязана повторять DO (ADR-033); отставание на минорную версию делает паритет неполным.
- Версию на managed-сервисе выбирает DO, не мы: кулдаун её не задерживает.

## Options considered

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Исключение: образ той же версии, что уже работает в managed-сервисе | паритет сразу; версия уже в проде | отступление от ADR-005 п. 3 | выбран владельцем |
| Ждать конца кулдауна | правило без исключений | паритета нет до даты; повторится при каждом обновлении DO | отклонён |
| Расширить п. 4 на любые «нужные» версии | - | размывает правило | отклонён |

## Decision

1. Локальный образ сервиса, который в проде работает как managed-сервис DO, берётся без кулдауна, если версия образа равна версии в проде.
2. Исключение относится только к образам локальной среды (`compose.yaml`); пакеты, образы приложений и actions проходят кулдаун по ADR-005.
3. Версия в проде подтверждается источником (`doctl`, запрос к серверу) и называется в записи или комментарии у образа.
4. Первое применение: `postgres:18.6` в `compose.yaml` (ADR-033).

## Consequences

- Плюс: локальный Postgres совпадает с DO сразу после обновления DO.
- Минус: образ новее кулдауна попадает на машину владельца; вредоносный или сломанный выпуск образа не отсекается кулдауном.
- Минус: проверка «версия равна версии в проде» ручная.
- Дальше: ADR-005 не меняется; он по-прежнему задаёт общее правило.

## Confirmation

Только ревью: версия образа в `compose.yaml` сверяется с версией на DO (`doctl databases get`, `select version()`).

## Revisit when

- Исключение применяют к образу, версия которого в проде не подтверждена.
- Выпуск образа, взятого по этому исключению, оказывается вредоносным или сломанным.
