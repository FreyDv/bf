## Context

Развилка `security-baseline` (R7, R19) требует ответа на каждую ось `security-baseline.md`, включая «не применимо». Черновик составлен по коду; пункты, которых в коде не видно, помечены.

## Options considered

- Принять ось-в-ось ответы ниже - предлагается.
- Оставить без записи - отклонено R7: безответная ось решается случайно.

## Decision

| Ось                         | Ответ                                                                                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Секреты                     | env и секреты ECS; в репозитории только dev-пара RS256 в `.env.example`; сканирование `gitleaks` в CI (`.github/workflows/gitleaks.yml`) |
| Аутентификация              | RS256 JWT, 15 мин, вращающиеся refresh-токены (ADR-019)                                                                                  |
| Авторизация                 | роли на edge (`ROUTE_ROLES`) + `AuthedMiddleware`/`AdminMiddleware` в сервисах                                                           |
| Валидация входа             | zod-схемы контрактов `@bf/contracts` на границе; class-validator на REST-контроллерах auth                                               |
| Вывод и инъекции            | Drizzle с параметризованными запросами; строковых SQL нет (не проверено автоматически)                                                   |
| Транспорт и заголовки       | CloudFront + ALB; response-headers policy (nosniff, X-Frame DENY, referrer, permissions) по `docs/aws-target-architecture.md`            |
| Rate limiting               | edge: лимит на пользователя или IP (`EDGE_RATE_LIMIT`, `EDGE_RATE_TTL_MS`)                                                               |
| Логирование и приватность   | Pino с редактированием путей (`redaction.config.ts`); срок хранения логов - **не определён**                                             |
| Зависимости                 | точные пины и кулдаун - ADR-030 (сейчас диапазоны `^`)                                                                                   |
| Права CI                    | `contents: read` у gitleaks и spec-guard; права конвейера - **не проверены**                                                             |
| Границы агента              | `.claude/settings.json` + хуки: запрет записи в удалённую БД, force-push, секретов CI                                                    |
| Данные в покое              | Aurora шифрование и снимки (`db-snapshot.yml`); проверка восстановления - **не проводилась**                                             |
| Состязательное тестирование | не применимо сейчас: нет разбора недоверенных байтов                                                                                     |
| Модель угроз                | **не написана**; параграф «кто и зачем атакует» - backlog REC-2                                                                          |
| Работа под эмбарго          | публичная уязвимость разрабатывается в приватной копии репозитория (R3); владелец снимает эмбарго                                        |
| Негативная область          | не определена                                                                                                                            |

## Consequences

- Плюс: ни одна ось не остаётся без ответа.
- Минус: пункты «не проверено»/«не определён» остаются открытыми до подтверждения.

## Confirmation

Ревью; `gitleaks` и хуки - автоматически; остальное - ручное.

## Revisit when

Появляется платёжный провайдер, персональные данные клиентов или внешний вход (тогда пересматриваются оси секретов, авторизации и данных в покое).
