# ADR-026: Реестр образов: GitHub Container Registry, образы публичные

| | |
| --- | --- |
| **Status** | Accepted |
| **Date** | 2026-11-10 |
| **Author** | владелец |
| **Decided by** | владелец |
| **Tags** | stack, ci, registry, deploy |

## Context

- ADR-018: образ каждого приложения при merge в `main` уходит в реестр с тегом по SHA; реестр не выбран.
- ADR-019: кластер `malinina` (ADR-017) тянет образы по тегу из `deploy/apps/<app>/image.yaml`.
- Репозиторий публичный.
- Новый платный ресурс требует ADR (AGENTS.md, красный флаг 3); бюджет облака ограничен.

## Options considered

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| GHCR, публичные образы | бесплатно для публичных; в CI хватает `GITHUB_TOKEN`; кластеру не нужен pull-секрет; нет нового ресурса | образ читает любой; второй провайдер рядом с DO | выбран |
| DO Container Registry | подключается к DOKS одной настройкой; один провайдер | платный сверх малого тарифа; токен DO в CI | отклонён |
| GHCR, приватные образы | образ закрыт | pull-секрет в кластере; платная квота | не рассматривался: репозиторий публичный |

## Decision

1. Образы публикуются в `ghcr.io/<владелец>/<приложение>`.
2. Пакеты публичные. Нужная видимость проверяется после первой публикации, не предполагается.
3. CI публикует через `GITHUB_TOKEN` с правом `packages: write` только в job сборки на `main`.
4. Кластер тянет образы анонимно: `imagePullSecret` не заводится.
5. Тег - SHA коммита (ADR-018); `latest` не публикуется.
6. В образ не попадают секреты и `.env`: секреты только через Sealed Secrets (ADR-020).
7. Старые образы удаляются политикой хранения (последние N по SHA плюс тот, что в `image.yaml`).

## Consequences

- Плюс: нет платного ресурса и токена реестра; ADR-020 сохраняет только токен GitHub App (ADR-019).
- Минус: скомпилированный код и версии зависимостей публичны.
- Минус: приватный пакет по ошибке сломает выкатку: кластер не скачает образ.
- Минус: GitHub - единая точка отказа для сборки и для образов.
- Дальше: workflow публикации (CI-2); политика хранения N; сканирование слоёв на секреты.

## Confirmation

Шаг CI после публикации проверяет, что образ скачивается без авторизации. Ревью: в Dockerfile нет `COPY .env` и `ARG` с секретами. Политика хранения - настройка в GitHub, автоматической проверки нет.

## Revisit when

- Репозиторий становится приватным или в образ нужно положить непубличный код.
- Лимиты GHCR для публичных пакетов вводятся или меняются.
- Скорость скачивания из GHCR в кластер DO мешает выкатке.
