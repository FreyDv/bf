## Context

Платформа - несколько NestJS-сервисов, два Next.js-приложения и общие пакеты, которые делят типы и релизный цикл. Исходная таблица решений фиксировала pnpm 10 + Turborepo и Node 22; версия Node с тех пор определяется ADR-031.

## Options considered

В исходной таблице альтернативы не записаны.

## Decision

Один монорепозиторий (топология репозитория, ответ на развилку `repo-topology`): pnpm 10 + Turborepo; единый формат модулей CJS во всех приложениях и пакетах (Nest CLI/SWC, tsup CJS dist).

## Consequences

- Плюс: Jest без боли с ESM; настройки Nest по умолчанию; один формат модулей на всё.
- Минус: зависимости, которые выходят только в ESM, потребуют обходного пути.

## Confirmation

`pnpm build`, `pnpm test` и `pnpm deps` идут через Turborepo; формат модулей закреплён конфигами `@bf/config`.

## Revisit when

Появляется зависимость, которую нельзя использовать из CJS без обходного пути, либо Nest/Jest перестают поддерживать CJS как основной режим.
