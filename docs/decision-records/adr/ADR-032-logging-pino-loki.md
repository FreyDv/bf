## Context

- Решения про логи нет; есть только порт логгера в shared kernel (ENF-4), контекст запроса с correlation id (ENF-5) и запрет секретов в метаданных ошибок (ERR-6).
- Платформа - Kubernetes на DigitalOcean, Spaces уже создан (ADR-017); сервисы кластера - поды (ADR-017, п. 3).
- Всё ведёт один человек (ADR-017).
- Нужны: библиотека, хранение, обработка, поиск.

## Options considered

**Хранение и поиск.**

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| Loki и Grafana в кластере, чанки в Spaces | дёшево; поиск по меткам и тексту; в стиле ADR-017 и ADR-019 | ещё один сервис для одного человека | выбран |
| Только stdout и `kubectl logs` | ничего не ставим | нет хранения после перезапуска пода, нет поиска | отклонён |
| Внешний SaaS | нет своих подов | платная зависимость вне DO; логи уходят третьей стороне | отклонён |
| Managed OpenSearch на DO | полнотекстовый поиск | заметно дороже и тяжелее | отклонён |

**Библиотека.**

| Вариант | Плюсы | Минусы | Итог |
|---|---|---|---|
| pino через nestjs-pino | JSON в stdout; быстрый; контекст запроса | новая зависимость | выбран |
| Встроенный Nest Logger | без зависимости | нет структурных JSON-логов из коробки | отклонён |
| winston | распространён | тяжелее и медленнее pino | отклонён |

## Decision

1. Логгер - pino через nestjs-pino, только в `apps/backend`; логи - JSON в stdout.
2. Код пишет через порт логгера из shared kernel (ENF-4); pino - адаптер в infrastructure; домен pino не видит (DEP-3, DEP-4).
3. Каждая запись несёт correlation id из контекста запроса (ENF-5).
4. Секреты и персональные данные в лог не попадают (ERR-6); список скрываемых полей настраивается в адаптере.
5. Логи из подов собирает и хранит Loki в кластере, чанки лежат в Spaces; поиск - Grafana.
6. Версии точные, кулдаун 7 дней (ADR-005); Loki и Grafana ставятся чартами, закреплёнными по версии (ADR-019).

## Consequences

- Плюс: структурные логи с одним correlation id через все слои.
- Плюс: поиск по меткам и тексту без платного сервиса.
- Минус: Loki и Grafana - ещё два сервиса в кластере, их надо обновлять и следить за диском и Spaces.
- Минус: срок хранения и потолок цены не заданы (backlog OBS-1).
- Дальше: сборщик логов с узлов, размеры, доступ к Grafana, схема полей записи - при деплое (OBS-1).

## Confirmation

Только ревью: пакета и сервисов ещё нет. Импорт pino вне infrastructure ловит `pnpm deps` (ADR-014).

## Revisit when

- Loki не справляется с объёмом логов или поиск медленный для разбора инцидентов.
- Нужны метрики и трассировки, и логи удобнее вести тем же инструментом.
- Расходы на Loki и Spaces заметно выше цены внешнего SaaS.
