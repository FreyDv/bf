## Context

Потребителю нужен контроль над офсетами и транзакциями для inbox-потока.

## Options considered

- `@nestjs/microservices` - не выбран: тоньше контроль над офсетами нужен для inbox.

## Decision

Использовать kafkajs напрямую. Решение отложено вместе с кодом потребителя (ADR-021).

## Consequences

- Сейчас в коде нет ни брокера, ни потребителя.

## Confirmation

Не применимо, пока нет потребителя.
