## Context

- Репозиторий содержал набросок: монорепо NestJS-сервисов, инфраструктуру AWS, 23 сжатых решения и спеки к этому коду.
- Владелец: «это просто набросок нового репозитория, вся инфра устарела; хочу сесть как за новый».

## Options considered

| Вариант | Итог |
|---|---|
| Мигрировать прототип под стандарт | отклонён владельцем |
| Удалить прототип на ветке, история `main` нетронута | выбран |
| Переписать историю `main` (force-push) | не выбран: необратимо, общий репозиторий; решение за владельцем отдельно |

## Decision

1. Код, инфраструктура, конвейер, скрипты и записи решений прототипа удалены коммитом ветки.
2. Они остаются в истории `main` (последний коммит прототипа `7c7928a`) и **не являются источником правил**.
3. Решения прототипа (стек, AWS, tRPC, бюджет) не переносятся; любое возвращается только новым ADR.

## Consequences

- Плюс: ничего устаревшего не сбивает будущие сессии.
- Минус: прежний код доступен только через историю git.

## Confirmation

В дереве нет `apps/`, `packages/`, `infra/` прототипа; `git log 7c7928a` показывает прототип.

## Revisit when

Владелец хочет вернуть часть прототипа или очистить историю `main`.
