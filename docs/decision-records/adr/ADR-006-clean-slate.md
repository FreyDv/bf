## Context

Репозиторий содержал набросок: монорепозиторий NestJS-сервисов, инфраструктуру AWS, 23 сжатых решения и спеки к этому коду. Владелец: «это просто набросок нового репозитория, вся инфра устарела; хочу сесть как за новый».

## Options considered

- Мигрировать прототип под стандарт - отклонено владельцем.
- Удалить прототип с ветки, оставив историю `main` нетронутой - выбрано.
- Переписать историю `main` (force-push) - не выбрано: необратимо и затрагивает общий репозиторий; решение за владельцем отдельно.

## Decision

Код, инфраструктура, конвейер, скрипты и записи решений прототипа удалены в коммите ветки; они остаются в истории `main` (последний коммит прототипа `7c7928a`) и **не являются источником правил**. Технологический стек не выбран; решения прототипа (стек, AWS, tRPC, бюджет) не переносятся. Любое из них возвращается только новым ADR.

## Consequences

- Плюс: ничего устаревшего не сбивает будущие сессии.
- Минус: прежний код доступен только через историю git.

## Confirmation

В дереве нет `apps/`, `packages/`, `infra/`; `git log 7c7928a` показывает прототип.

## Revisit when

Владелец хочет вернуть часть прототипа или очистить историю `main`.
