## Context

Один путь кода для локальной разработки и прода без секретов на ECS.

## Options considered

В исходной таблице альтернативы не записаны.

## Decision

`@bf/storage` - порт S3: если задан `S3_ENDPOINT`, используется MinIO (path-style, статические учётные данные), иначе - цепочка учётных данных AWS по умолчанию (роль задачи).

## Consequences

- Плюс: единый путь кода; на ECS нет секретов.

## Confirmation

`packages/storage` и его in-memory реализация для тестов.

## Revisit when

Нужен второй провайдер хранилища.
