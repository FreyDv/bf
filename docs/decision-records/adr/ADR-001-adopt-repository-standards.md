## Context

Владелец поручил зафиксировать знания стандарта repositorystandards.com в репозитории так, чтобы каждая будущая сессия планирования, кода и ревью следовала им без отступлений. Знание, живущее только в чате или памяти агента, для стандарта не существует (R3).

## Options considered

- Держать правила в памяти агента - отклонено (R3).
- Внедрить частично - отклонено владельцем («мигрировать всё»).
- Внедрить полностью - выбрано.

## Decision

Репозиторий следует Repository Standards 1.0.19, профиль **core** (один автор, работа не передаётся асинхронно). Знания лежат в `docs/standards/` (источники дословно, дайджесты, обоснования), правила грузятся из `.claude/rules/`, исполнение обеспечивают гарды (`scripts/*.mjs`, хуки `.claude/hooks/`) и CI. Отклонение допустимо только записанное. Слой 2 (стек) не применяется, пока стек не выбран (ADR-ы по развилкам, backlog STACK-1).

## Consequences

- Плюс: каждая сессия начинает с одних правил; дрейф виден числом.
- Минус: накладные расходы на спеки и записи решений.

## Confirmation

`node scripts/self-verify.mjs` (дрейф 0), `spec-guard.yml` на каждый PR, `scripts/verifyAgentGuards.sh`.

## Revisit when

Профиль меняется на scale (работа передаётся другим людям) либо стандарт меняет нормативное ядро несовместимо с записанными исключениями.
