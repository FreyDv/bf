# ADR-001: Внедрить Repository Standards (профиль core)

## Context

- Владелец поручил записать знания стандарта repositorystandards.com в репозиторий так, чтобы каждая сессия планирования, кода и ревью следовала им без отступлений.
- Знание, которое живёт только в чате или памяти агента, для стандарта не существует (R3).
- Автор один, работа другим людям не передаётся.

## Options considered

| Вариант | Итог |
|---|---|
| Держать правила в памяти агента | отклонён: R3 |
| Внедрить частично | отклонён владельцем («мигрировать всё») |
| Внедрить полностью | выбран |

## Decision

1. Репозиторий следует Repository Standards 1.0.19, профиль **core**.
2. Знания лежат в `docs/standards/`: источники дословно, дайджесты, обоснования.
3. Правила грузятся из `.claude/rules/`; исполнение - гарды (`scripts/*.mjs`, хуки `.claude/hooks/`) и CI.
4. Отклонение допустимо только записанное.
5. Слой 2 стандарта (стек) применяется через стековые ADR (ADR-007 и дальше).

## Consequences

- Плюс: каждая сессия начинает с одних правил; дрейф виден числом.
- Минус: накладные расходы на спеки и записи решений.

## Confirmation

`node scripts/self-verify.mjs` (дрейф 0), `spec-guard.yml` на каждый PR, `scripts/verifyAgentGuards.sh`.

## Revisit when

- Профиль меняется на scale: работа передаётся другим людям.
- Стандарт меняет нормативное ядро несовместимо с записанными исключениями.
