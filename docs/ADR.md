# Architecture decision records (condensed)

Full discovery + ~100 resolved questions live in the planning doc; these are the load-bearing decisions.

| #   | Decision                                                                                                                                                                                                                                                                                                                            | Why                                                                                                                                                                                                                                              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | pnpm 10 + Turborepo, Node 22, CJS everywhere (Nest CLI/SWC + tsup CJS dist)                                                                                                                                                                                                                                                         | Jest without ESM pain; Nest defaults; one module format across apps and packages                                                                                                                                                                 |
| 2   | ESLint flat + Prettier + tsconfig bases in `@bf/config` (not oxlint/oxfmt from the boilerplate)                                                                                                                                                                                                                                     | Team familiarity, plugin ecosystem (import-x, unused-imports)                                                                                                                                                                                    |
| 3   | Per-app Drizzle: config + `schema.register.ts` + committed migrations per app, one Postgres, **pg schema per app**                                                                                                                                                                                                                  | Isolation without a DB per service; `@bf/db` hard-codes `casing: snake_case` on both kit and runtime                                                                                                                                             |
| 4   | Hexagonal per bounded context (`domain/application/infrastructure/presentation`) enforced by dependency-cruiser                                                                                                                                                                                                                     | Domain stays framework-free and unit-testable with zero infra                                                                                                                                                                                    |
| 5   | `@nestjs/cqrs` for commands/queries; integration events via **transactional outbox + Debezium → Kafka**                                                                                                                                                                                                                             | Atomic aggregate+event writes; no dual-write; consumers idempotent via inbox table                                                                                                                                                               |
| 6   | Event envelope validated with zod; topic = `<context>.<aggregate>.<event>`; DLQ = `<topic>.dlq`                                                                                                                                                                                                                                     | Contract between services independent of the broker client                                                                                                                                                                                       |
| 7   | kafkajs directly (not `@nestjs/microservices`)                                                                                                                                                                                                                                                                                      | Offset/transaction control for inbox flow; thinner coupling                                                                                                                                                                                      |
| 8   | Pino + nestjs-cls; OpenTelemetry started before Nest; prom-client `/metrics`; terminus `/health`                                                                                                                                                                                                                                    | Same observability surface on every app via `@bf/server`                                                                                                                                                                                         |
| 9   | `@bf/storage` S3 port: `S3_ENDPOINT` set ⇒ MinIO (path-style, static creds), unset ⇒ AWS default credential chain                                                                                                                                                                                                                   | One code path for local and prod; no secrets on ECS (task role)                                                                                                                                                                                  |
| 10  | `@bf/llm` OpenAI adapter behind a port with an in-memory test double                                                                                                                                                                                                                                                                | Tests never hit the network; provider swappable                                                                                                                                                                                                  |
| 11  | AWS: ECS Fargate via SAM/CloudFormation nested stacks; Kafka/Debezium deferred (worker `DesiredCount=0`)                                                                                                                                                                                                                            | Managed compute without k8s; MSK added later without code changes (`KAFKA_ENABLED`)                                                                                                                                                              |
| 12  | Global DI tokens use `Symbol.for('bf.*')`                                                                                                                                                                                                                                                                                           | Packages ship subpath bundles; plain `Symbol()` would be duplicated per bundle                                                                                                                                                                   |
| 13  | TypeScript 6.0 (not 7): `baseUrl` removed from tsconfigs, `rootDir` explicit, `ignoreDeprecations: 6.0` only where tsup injects `baseUrl`                                                                                                                                                                                           | `@nestjs/schematics@12` requires TS ≥6; typescript-eslint supports <6.1                                                                                                                                                                          |
| 14  | ESLint 10.10 with `@eslint-react/eslint-plugin` instead of `eslint-plugin-react`                                                                                                                                                                                                                                                    | eslint-plugin-react 7.x breaks on ESLint 10 (`getFilename` removed)                                                                                                                                                                              |
| 15  | `pnpm.overrides` pin one `@nestjs/common                                                                                                                                                                                                                                                                                            | core@12`                                                                                                                                                                                                                                         | `@nestjs/throttler` still declares Nest ≤11 peers; without the override pnpm installs a second Nest copy and DI breaks |
| 16  | **Service split (Sept 2026)**: `api` (edge: JWT, roles, rate limit, proxy `/<svc>/*`), `auth` (identity), `order`, `course`, `billing`, `admin`, `ai`; Next.js `fe-main` + `fe-admin`; `worker` removed                                                                                                                             | First approximation of the target topology, minimal on purpose, to evaluate the approach                                                                                                                                                         |
| 17  | Inter-service RPC = **nestjs-trpc** (Nest 12 via `peerDependencyRules`), **contract-first**: hand-written zod schemas in `@bf/contracts/<svc>/schemas.ts`, `AppRouter` type generated by the nestjs-trpc CLI into `@bf/contracts/<svc>/router.ts`, drift checked in CI; consumed via `workspace:*`, never published                 | Types shared without a registry; every procedure has explicit input+output so the generated file is self-contained                                                                                                                               |
| 18  | **One Postgres, one database per service** (`auth`, `order`, `course`, `billing`, `admin`; public schema), created by `infra/postgres/postgres-init/01-init.sql`; supersedes #3                                                                                                                                                     | Hard data isolation between services while still one container locally                                                                                                                                                                           |
| 19  | **RS256 JWT**: `auth` signs with `JWT_PRIVATE_KEY`, every service verifies locally with `JWT_PUBLIC_KEY` (no JWKS fetch); access 15m + opaque rotating refresh tokens (sha256 at rest); external login providers not implemented yet                                                                                                | No shared secret, no per-request call to auth; identity is forwarded by the edge as trusted `X-User-*` headers (stripped from clients first)                                                                                                     |
| 20  | Single root `docker-compose.yml` (infra include + every app from `docker/nest.Dockerfile` / `docker/next.Dockerfile`, one-shot `migrate` service); apps take their committed `.env.example` + container overrides                                                                                                                   | `pnpm stack:up` boots the whole platform; no publishing pipeline needed                                                                                                                                                                          |
| 21  | **Kafka, prom-client, OpenTelemetry dropped from the code/deps (Sept 2026)**; redis/debezium/nats/clickhouse/kafka/otel/prometheus stay only as `infra/*` compose files for later. The outbox table + `OutboxEventPublisher` stay (DB-only, no broker); #5, #7, #8 are superseded for now (no consumer, no `/metrics`, no tracing). |
| 22  | **AWS on one EC2 host (Oct 2026), supersedes #11**: `docker compose` + Caddy on a `t4g.medium`, Aurora Serverless v2 with min 0 ACU (auto-pause), public subnets only (no NAT/ALB), infra as AWS CDK in TypeScript, every ops/CI script in TypeScript on AWS SDK v3 run by plain `node`; deploys through SSM Run Command            | Budget cap of $100–150/mo (Fargate + ALB + NAT + RDS was ≈ $180; this is ≈ $40–85). Trade-offs accepted: single point of failure, no app autoscaling, ~15 s resume after a DB pause; logical replication (Debezium) would keep the cluster awake |
