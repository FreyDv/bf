## What was said

- Бюджет AWS 100-150 USD/мес; один EC2 с масштабируемой до нуля Aurora; простой и пароль БД по IP-списку; домен malinina.ca (→ `BDR-002`, `ADR-022`).
- Миграция на ECS Fargate + CloudFront/S3 со сном до нуля; решения: Service Connect, задачи 0,5 vCPU / 1 ГБ, два стека `bf-prod` и `bf-prod-apps`, группы логов на приложение, `desiredCount` не задаётся (→ `ADR-023`).
- Никакого DynamoDB: состояние оркестратора = число задач ECS + теги сервиса, без дополнительного хранилища (→ `ADR-023`, `BDR-002`).
- Ops- и CI-скрипты - TypeScript, запуск обычным `node`; инфраструктура - CDK; никакого bash (→ `ADR-022`, `AGENTS.md`).
- Всё общение - только tRPC, contract-first; никаких ad-hoc REST; ресурсы находит AWS SDK, а не id в env (→ `ADR-017`, `AGENTS.md`).
- Токены DI - `Symbol.for`; оговорки nestjs-trpc, throttler и ConfigModule (→ `ADR-012`, `ADR-015`, `ADR-017`).
- Разделение на сервисы, RS256 JWT, база на сервис, один корневой compose (→ `ADR-016`, `ADR-019`, `ADR-018`, `ADR-020`).
